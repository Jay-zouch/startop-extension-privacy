星拓广告辅助插件 · 隐私政策

更新日期：2026年11月25日　适用于 Chrome 应用商店版

本扩展是用于内部电商运营协作的免费辅助工具，与星拓或 Google 无隶属关系。它在用户已登录的星拓页面中展示广告组合、ASIN 历史指标、库存及团队备注，不用于广告营销或出售用户数据。

处理的数据及用途

  • 当前星拓账号显示姓名：在用户新增备注时保存该条作者署名；不会将角色、部门作为署名。
  • 当前页面的站点、店铺、广告实体标识、ASIN、广告指标及运营日志：用于精确匹配组合成员、显示历史数据及 Deals 标记。
  • 监控服务中的产品、价格、评分和仓库库存：用于已授权产品的数据查询。
  • 用户输入的备注正文、作者、时间及条目标识：同步至运营者管理的监控服务，用于同一产品的团队协作，已授权账号可看到相应共享备注。
  • 星拓页面已有的登录令牌及签名信息：仅在当前星拓页面内用于向星拓自身 HTTPS 接口发送已登录请求，不由本扩展发送至监控服务。本扩展不读取密码。监控服务使用用户自己的既有登录会话进行身份及权限校验。

传输与存储

商店版仅通过 HTTPS 访问星拓及运营者监控服务（https://124.222.130.207:18443）。备注及相关业务数据存储在运营者管理的服务器。扩展在浏览器本地保存界面偏好、已核验的组合/产品缓存及性能诊断设置；未确认保存的草稿在当前页面内保留。

可选性能诊断默认关闭；开启后仅在本机保留最近最多40条经筛选的时间、界面类型、状态和耗时，不记录备注正文、账号姓名或登录令牌。用户可在扩展的性能诊断页面关闭并清除这些记录。

人员许可

插件启动时通过监控服务检查已登录账号及管理员批准状态；运行期间约每15秒重新验证。每次插件服务器业务请求也进行许可及产品分配校验。网络断开、登录失效、许可撤销或分配范围变化时，官方商店版会停止展示插件界面并要求重新验证。管理员停用账号与插件时会注销旧会话，已有业务记录不随账号停用而删除。此机制不能收回用户此前已经下载或自行复制的数据。

共享、权限与用途限制

数据仅用于用户请求的产品查询和团队备注协作；不出售，不用于定向广告，不提供给数据经纪商，不用于信用或借贷决策。本扩展对用户数据的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）。只有用户已登录且具有相应权限时才能查询或修改受保护的数据。仅持有安装链接并不授予业务数据访问权限。

保存期限与删除

备注保留至用户清空删除或管理员处理；删除后从正常界面和查询结果中移除，服务器可能保留空的条目标识以防止重试恢复已删除内容。业务记录及服务器备份按运营者的业务管理需要保留。用户可通过下方邮箱申请查询、更正或删除相关个人数据；卸载扩展会移除扩展本地存储，但不会自动删除团队服务器数据。
